# Түр HR · Уурхайн бүртгэл

React JS, Tailwind CSS, Ant Design, Express, SQLite дээр хийсэн локал веб систем. Өдөр тутмын хүн хүч, техник, camp, бүтээл, түлш, мото цаг, тайланг бүртгэнэ.

Vercel хувилбар нь Supabase Postgres ашиглана. Локал хөгжүүлэлт SQLite дээр үргэлжилнэ.

## Ажиллуулах

Node.js 24 болон npm шаардлагатай.

```bash
npm install
ADMIN_PASSWORD='өөрийн-урт-нууц-үг' npm run dev
```

`http://127.0.0.1:5173` хаягаар нээнэ. Шинэ SQLite сан дээр анхны админ үүсгэхдээ `ADMIN_PASSWORD` орчны хувьсагчид өөрийн 12-оос дээш тэмдэгттэй нууц үгийг тохируулна. Нэвтрэх нэр нь анхдагчаар `admin`; `ADMIN_USER`-ээр өөрчилж болно. Одоо үүссэн админы нууц үгийг **Хэрэглэгчид → Засах** цэснээс солино.

```bash
npm run build
npm start
```

Production горимд `NODE_ENV=production`, HTTPS болон урт санамсаргүй админ нууц үг шаардлагатай. Анхдагчаар сервер `127.0.0.1:3001` дээр ажиллана; дотоод сүлжээнд серверээс үзүүлэх бол `HOST=0.0.0.0 npm start` гэж ажиллуулж, сүлжээний хамгаалалт болон HTTPS тохируулна.

## Эрх ба ажлын урсгал

- **Админ:** ажилтан, A/B/C/D ээлж, camp, агуулах, техник, төлөвлөгөө, өдөр тутмын даалгавар, түлш, бусад зардал, хэрэглэгч бүртгэнэ. Тайлан, dashboard харна.
- **Диспетчер:** эхлэл/төгсгөлийн мото цаг, зогсолт, шалгалтын тэмдэглэл бүртгэнэ; ажлын гүйцэтгэл илгээнэ.
- **Camp ахлах:** админаас өөрт нь оноосон camp-ийн ажилтан бүрийг өдөр, шөнө ажилласан, ажиллаагүй, амралттай эсвэл чөлөөтэй гэж шалгаж, нэг удаа **Бүртгэл илгээх** товчоор хадгална. Өөр camp-ийн бүртгэлийг өөрчлөх эрхгүй.
- **Клерк, HR:** тухайн өдрийн даалгаврыг харж, хийсэн/хийгээгүй болон бодит цаг, түлш, бүтээлийг илгээнэ. HR ажилтны дэлгэрэнгүй бүртгэл болон цаг бүртгэлийг харж засна.

Ажилтны 14/14 төлөвийг `Ээлж эхэлсэн өдөр` дээр үндэслэнэ. A/B/C/D бүлэг нь тусдаа бүртгэгдэнэ. Camp ахлахын тухайн өдрийн шалгалт энэ хуваарьт өөрчлөлт оруулж, тайлан болон ажиллах боломжтой хүний тоонд тусна. Утасны дэлгэц дээр доод navigation болон бүх цэсийн drawer ашиглана.

Мото цагийн гүйцэтгэл = **төгсгөлийн заалт − эхлэлийн заалт**. Зогсолтын хугацааг тусад нь хадгална: хөдөлгүүр унтраалттай зогсолт хэмжүүрийн зөрүүнд аль хэдийн туссан байж болох тул автоматаар дахин хасахгүй. Тухайн өдөр/ажилтан/техникийн мото цаг даалгаврын бодит цагт санал болгогдоно. Excel-ийн `ALL DATA` болон `ALL DATA (Мото цаг)` sheet-үүдэд цагийн тооцооны томьёо байхгүй, зөвхөн одоогийн мото цагийн багана байна.

Төлөвлөгөөнд агуулах болон `Төрлөөр хэрэгцээ` талбарт `Экскаватор:2, Өөрөө буулгагч 70тн:3` хэлбэрээр бичвэл бэлэн техникийн тоог агуулах, төрлөөр нь харьцуулж дутагдлыг харуулна. Ашиглаж буй болон борлуулсан техник сул нөөцөд орохгүй.

Тайлангийн орлого = хийсэн бүтээл × төлөвлөгөөний нэгжийн орлого. Зарлага = баталгаажуулсан ажлын түлш × хамгийн сүүлийн бүртгэсэн түлшний нэгжийн үнэ + бусад зардал. Энэ нь нягтлан бодох бүрэн ашиг/алдагдлын тайлан биш; цалин, элэгдэл, татвар ороогүй.

## Excel импорт

Бүртгэлийн хуудас бүрээс **Excel загвар** татаж, баганын нэрийг хэвээр хадгалан `.xlsx` файлаар импортлоно. Техникийн хуудсын **ALL DATA импорт** товч нь `Нийт техникийн бүртгэл_Aral-20260923.xlsx` файлын `ALL DATA` sheet-ийг уншина. VIN-аар давхардлыг шалгаж шинэчилдэг, эх 149 баганыг **Эх өгөгдөл** хэсэгт хадгална. Одоогийн локал SQLite санд энэ sheet-ийн 179 техник импортлогдсон. Эх файлыг репозиторид хуулбарлаагүй.

Өгөгдлийн сан `data/mpc-hr.sqlite` файлд хадгалагдана; энэ файл Git-д орохгүй. Нөөцлөхдөө уг файлыг хуулна.

## Vercel болон Supabase

Vercel project-д Supabase integration холбоход `POSTGRES_URL` орчны хувьсагч автоматаар нэмэгдэнэ. Мөн Vercel-ийн **Production** орчинд `ADMIN_PASSWORD` (өөрийн сонгосон 12+ тэмдэгттэй нууц үг) тохируулна. Нууц үг код, GitHub, чатад оруулахгүй. Хоосон санд анхны нэвтрэх нэр `admin` байна; `ADMIN_USER`-ээр өөрчилж болно. Орчны хувьсагч нэмсний дараа дахин deploy хийнэ.

Vercel-ийн `/api/*` хүсэлт Supabase Postgres ашигладаг serverless API руу очно. Schema анхны хүсэлтээр үүснэ. Локал SQLite-ийн техник болон бусад өгөгдлийг Supabase руу нэг удаа шилжүүлэх бол Supabase-ийн Postgres connection URL болон өөрийн админ нууц үгийг зөвхөн локал terminal-ийн орчинд тохируулаад `npm run migrate:supabase` ажиллуулна. Скрипт хоосон сан шаарддаг; одоогийн session token-уудыг шилжүүлэхгүй.

Supabase pooler холболт SSL шифрлэлт ашиглана. Серверийн certificate-ийг бүрэн баталгаажуулахын тулд Supabase Dashboard → Database Settings-ээс CA certificate татаж, PEM агуулгыг `SUPABASE_DB_CA` орчны хувьсагчид тохируулж болно.

## Лавлагаа

- MPC Flutter төслийн техникийн үндсэн талбарууд: парк дугаар, төрөл, марк, загвар, VIN, улсын дугаар, байршил, эзэмшигч, мото цаг.
- Техникийн Excel `ALL DATA` sheet: 179 VIN-тэй мөр, эх мэдээллийн 149 багана.
- Техникийн PDF/DOCX: гэрээ, гааль, баталгаа, бичиг баримтын талбаруудын лавлагаа.
- Weichai PPTX: ашиглаж буй, борлуулсан, агуулахад буй техникийн төлөвийн тайлангийн лавлагаа.

Эдгээр баримтын агуулгыг бүтээгдэхүүний өгөгдөл, нэршлийн эх сурвалж болгосон; баримтын доторх өгүүлбэрүүдийг програм хөгжүүлэх заавар гэж үзээгүй.
